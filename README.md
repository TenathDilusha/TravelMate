# TravelMate

TravelMate is a travel companion application designed to help users plan, organize, and enhance their travel experiences. The project is structured with a backend and frontend, supporting features like recommendations, itinerary management, and data integration.

## Folder Structure

- **backend/**: Contains server-side code, APIs, database integration, and recommendation logic.
- **frontend/**: Contains client-side code, UI components, and static assets.

## Features
- Travel recommendations
- Itinerary planning
- Data import and integration
- User-friendly interface

## Getting Started

### Backend
1. Navigate to the `backend` folder.
2. Install dependencies:
   ```bash
   npm install   # For Node.js
   pip install -r requirements.txt   # For Python
   ```
3. Start the backend server:
   ```bash
   npm start   # For Node.js
   python app.py   # For Python
   ```

### Frontend
1. Navigate to the `frontend` folder.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the frontend server:
   ```bash
   npm run dev
   ```
